專題

主題：慢性腎臟病(CKD)風險因子分析與視覺化決策儀表板

使用工具：Python、Power BI、Streamlit

簡述：
利用 Kaggle 網站上的 Testing_CKD_dataset.csv， 使用 Python 進行資料前處理與分析， 並透過 Power BI 建立視覺化儀表板， 探討 BMI、年齡以及是否具相關病史等因素， 對罹患慢性腎臟病（CKD）機率的影響， 協助進行資料導向的健康風險判斷與決策。 再利用Streamlit套件開發互動式網頁， 讓使用者能夠輸入個人資訊， 即時獲得CKD風險評估結果， 提升專題的實用性
